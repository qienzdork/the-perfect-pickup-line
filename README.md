# The Perfect Pickup Line

A single original pickup line an AI agent could actually say out loud: a machine
that ran a million simulations of this moment — and in every one of them, you
smiled. Charming, self-aware, one breath, no pressure.

`main.py` writes the line deterministically to `$OUTPUT_PATH` (default
`/output/entry.txt`).
